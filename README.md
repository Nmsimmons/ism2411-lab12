# ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

**Author:** Noah Simmons

## Description
This project uses Python to read sales data from a CSV file, calculate total revenue, filter high-value sales, and create a cleaned CSV report.

It also uses dictionaries to summarize sales by product and creates a log file that records total revenue each time the program runs.

## Files
- `csv_practice.py` - Main Python program containing Exercises 1–8.
- `data/sales.csv` - Original sales data.
- `data/cleaned.csv` - Filtered sales with totals greater than $100.
- `data/run_log.txt` - Records the date, time, and total revenue each time the program runs.
